# Job Posting Service

Spring Boot service that handles CRUD operations for companies, job postings, applications, and job alerts.

## Tech Stack

- Spring Boot 3.3 / Java 21
- PostgreSQL 16
- Redis 7 (caching)
- Firebase Admin SDK (JWT verification)
- Azure Service Bus (publishing new job events)
- Port: 8081
